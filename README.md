# Семейный финансовый бот — черновик

Telegram-бот для двоих: баланс месяца, траты с автокатегориями, выписки по каждому, учёт долгов.
Python 3.10+, без внешних зависимостей, база SQLite. Суммы хранятся в копейках (целые числа) — расчёты точные, без плавающей точки.

## Как это выглядит для пользователя

Внизу чата постоянные кнопки: **💰 Баланс · 📋 Выписка · 💳 Долги · ❓ Помощь**.

### Внести трату — одно сообщение

```
ты: 450 такси
бот: ➖ 450 ₽ — такси
     🚕 Транспорт · Саша
     [✏️ Категория] [🗑 Удалить]
```

Порядок неважен (`такси 450` тоже работает), понимает `1 200`, `1200,50`, `1,5к`, `40 тыс`, `2 млн`.
Категория ставится сама. Если не угадал — жмёшь «✏️ Категория», выбираешь свою, и бот **запоминает**: в следующий раз «вкусвилл» сам ляжет в Продукты.
Второму супругу прилетает короткое уведомление о каждой операции.

### Доход

```
ты: +150000 зарплата     (или: аванс 40к)
бот: 💵 Доход 150 000 ₽ — зарплата
```

### Баланс месяца — кнопка «💰 Баланс»

```
💰 Сентябрь 2026

Доходы:  150 000 ₽
Расходы: 45 200 ₽
Остаток: +104 800 ₽

По людям:
  Саша: доходы 150 000 ₽, расходы 30 000 ₽
  Аня: доходы 0 ₽, расходы 15 200 ₽

💳 Открытых долгов: 2 на 340 000 ₽
[◀️ Август]  [Октябрь ▶️]
```

### Выписка — кнопка «📋 Выписка»

Сверху переключатели **Вся семья / Саша / Аня** и стрелки по месяцам — одно сообщение, которое перерисовывается кнопками, чат не засоряется.

```
📋 Выписка · Сентябрь 2026 · вся семья

Доходы 150 000 ₽ · Расходы 45 200 ₽

Расходы по категориям
🛒 Продукты — 18 300 ₽ (40%)
🚕 Транспорт — 4 200 ₽ (9%)
...

Последние операции
01.09 · Саша · −450 ₽ · такси
```

### Долги

```
ты: долг Иван 50000 за ремонт
бот: 💳 Записал долг: Иван — 50 000 ₽ (ремонт)

ты: погасил Иван 10000
бот: ✅ Погашение по «Иван»: 10 000 ₽
     Осталось: 40 000 ₽ из 50 000 ₽
```

Кнопка «💳 Долги» показывает все открытые долги с остатком и процентом погашения, под каждым — кнопка «➖ Погасить» (спросит сумму). Когда остаток доходит до нуля — долг закрывается сам, с праздничным сообщением. Переплата невозможна: платёж больше остатка записывается ровно на остаток, бот об этом предупреждает.

## Верность расчётов — как гарантируется

- Все суммы — **целые копейки**, никакого float.
- Итоги (баланс, категории, по людям) считает **SQL по базе** при каждом запросе — нет накапливаемых счётчиков, которые могут разойтись с данными.
- Удалённая операция помечается флагом (не стирается) и исключается из всех сумм.
- Месяц операции фиксируется по Москве в момент внесения.
- Остаток долга = исходная сумма − сумма всех платежей, тоже считается по базе.
- `test_bot.py` — 45 проверок: разбор сумм, форматирование, категории, суммы месяца (в т.ч. «сумма по людям = общей», «сумма категорий = расходу»), долги, обучение категорий. Все проходят.

## Ограничения черновика (сознательные)

- Доступ: первые **двое** написавших боту привязываются, остальным отказ (лимит меняется переменной `FIN_MAX_USERS`).
- Имя в отчётах берётся из Telegram, меняется командой `/имя Аня`.
- Погашение долга — отдельная запись, **не** попадает в расходы месяца автоматически (иначе задвоение, если платёж уже внесён как трата). Если нужно наоборот — скажи.
- Удалять можно только через кнопку 🗑 на карточке операции.

## Структура

```
finbot/
  __main__.py    точка входа: long polling, цикл обновлений
  handlers.py    обработка сообщений и кнопок
  cards.py       отрисовка карточек, баланса, выписки, долгов
  parsing.py     разбор фраз (траты, долги, правки) — чистые функции
  money.py       разбор сумм («1,5к» → 150 000 коп.) и форматирование
  categories.py  14 категорий + словарь ключевых слов
  db.py          SQLite: операции, долги, платежи, журнал правок
  dates.py       месяцы, московское время
  telegram.py    обёртка над Bot API (stdlib, без зависимостей)
backup.py        ночной бэкап базы (sqlite backup API)
test_bot.py      проверки расчётов: python3 test_bot.py
```

## Запуск

1. В BotFather: `/newbot` → получить токен.
2. `TG_TOKEN=<токен> python3 -m finbot`

На сервере: systemd-сервис `family-finance-bot`, деплой — `git push` с рабочей машины,
затем на сервере `git pull` и `systemctl restart family-finance-bot`.
База `finance.db` и файл `env` с токеном лежат в корне рядом с пакетом и в git не попадают.
